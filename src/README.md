# Código-fonte

Este diretório reúne os códigos-fonte usados nas aulas e práticas da disciplina.

## Organização

- `threads/`: exemplos de concorrência e paralelismo com threads, memória compartilhada e Fork–Join.

Os artefatos de compilação não devem ser gravados em `src/`. Os scripts da disciplina usam `build/`, que já é ignorado pelo Git.
