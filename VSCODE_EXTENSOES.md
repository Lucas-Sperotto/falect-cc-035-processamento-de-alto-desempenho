# Extensões do Visual Studio Code

Instale apenas o necessário para o seu ambiente e para a atividade em andamento.

## Essenciais

- **WSL**, da Microsoft — somente para quem usa Windows + WSL;
- **C/C++**, da Microsoft;
- **C/C++ Extension Pack**, da Microsoft;
- **CMake Tools**, da Microsoft;
- **Markdown All in One**;
- **Code Spell Checker**, com dicionário de português quando desejado.

## Conforme a atividade

- **Modern Fortran** — exemplos ou ferramentas em Fortran;
- **Python** e **Pylance** — scripts de apoio e análise;
- **Julia** — quando a linguagem for utilizada;
- **Extension Pack for Java** — quando a atividade exigir Java;
- **GitLens** — inspeção complementar do histórico.

A EAD 01 pode solicitar a verificação dessas ferramentas para padronizar o ambiente. Nas atividades seguintes, o enunciado informará quais delas são efetivamente necessárias.

## WSL

Abra o projeto a partir do terminal Linux com:

```bash
code .
```

Quando o VS Code indicar **Install in WSL**, instale a extensão no ambiente remoto. Uma extensão instalada apenas no lado Windows pode não enxergar compiladores e ferramentas do Ubuntu.

## Assistentes de IA

Copilot, Gemini Code Assist ou ferramentas equivalentes são opcionais. Sua instalação não autoriza o uso em todas as atividades. Consulte [POLITICA_IA.md](POLITICA_IA.md) e saiba desativar sugestões automáticas quando o enunciado marcar **IA não permitida**.

Evite instalar várias extensões com a mesma função. Elas podem conflitar, consumir recursos e tornar o ambiente mais difícil de reproduzir.
