# Atividades

Os enunciados e arquivos iniciais serão publicados em subdiretórios próprios.

Antes de começar uma atividade:

1. sincronize a `main` com o repositório oficial;
2. leia o enunciado e a rubrica;
3. confirme a regra de uso de IA;
4. crie a branch indicada;
5. revise o formato e o canal de entrega.

Não publique dados pessoais, executáveis ou arquivos destinados somente ao SIGAA.
